# Del Olmo Construction - Webflow Implementation Package

This repository contains all code artifacts, templates, and documentation for implementing the Del Olmo Construction website on Webflow.

## 📁 Project Structure

```
├── schema/              # JSON-LD structured data templates
├── css/                 # Custom CSS for theming and utilities
├── js/                  # Custom JavaScript for interactions
├── html/                # HTML embed snippets for integrations
├── cms/                 # Webflow CMS collection templates
├── docs/                # Implementation guides and documentation
└── assets/              # Supporting files and configurations
```

## 🎯 Quick Start

1. **Review the specification**: See `docs/SPECIFICATION.md` for complete requirements
2. **Set up Webflow project**: Follow `docs/WEBFLOW-SETUP.md`
3. **Implement schemas**: Copy JSON-LD from `schema/` into Webflow custom code
4. **Add custom code**: Integrate CSS and JS from respective folders
5. **Configure CMS**: Use templates in `cms/` to set up collections
6. **Integrate services**: Follow guides in `docs/integrations/`
